# Volty

Volty is an independent EV charging project building a clearer, more useful way to discover public charging infrastructure. The initial focus is a map-first iOS and Android app that brings charging locations and relevant network data together in one place.

Volty is being developed with an eMSP (e-Mobility Service Provider) model in mind, with an emphasis on reliable data, transparent charging information, and interoperability with charge point operators (CPOs).

## Goals

- Make it easier for drivers to find and understand public EV charging infrastructure.
- Aggregate location, connector, availability, and tariff information from suitable data sources.
- Build dependable integrations with charging networks using open interoperability standards.
- Create a foundation for a broader EV charging experience across discovery, planning, access, and payment.

## Planned product capabilities

The first release is planned as a mobile map experience for iOS and Android. Future development may include:

- Charging-station search and map exploration
- Connector, power, pricing, and availability information where supplied by operators
- Route planning and charging-stop recommendations
- In-app charging payments
- RFID card support
- Additional CPO, roaming, and data-provider integrations

Features and integrations are under active development and are not represented as live unless stated otherwise.

## Supported Regions
Currently, Volty only supports England, Scotland, Wales and Northern Ireland.
Mainland Europe and Ireland will follow when more CPOs are contacted.
> There are currently no plans to extend this to the Americas, Africa, Asia, and Oceania. This could change, depending on reception in the UK and Europe

## OCPI integration

Volty is designed to support OCPI 2.2.1 integrations with CPOs and roaming partners. This work is intended to enable standardised exchange of charging-location, tariff, availability, session, and related operational data as the project develops.

If you represent a CPO or roaming partner and would like to discuss an OCPI test integration, data access, or collaboration, please get in touch.

## Project status

Volty is in early development. Current work is focused on data aggregation, validating OCPI 2.2.1 integration flows, and establishing the foundations for the mobile app.

## Roadmap

1. Establish reliable charging-infrastructure data ingestion and validation.
2. Develop the map-first mobile application for iOS and Android.
3. Complete and test OCPI 2.2.1 integration workflows with willing CPO partners.
4. Expand discovery features with richer charging and tariff information.
5. Explore route planning, payment, RFID, and additional interoperability integrations.

The roadmap is directional and may change as partnerships, data availability, and user needs evolve.
